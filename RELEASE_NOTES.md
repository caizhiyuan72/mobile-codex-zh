# Codex CN v0.3.9-cn.5

Unofficial Android ARM64 modified build based on Mobile Codex v0.3.9.

### Changes

- Short launcher name: Codex CN.
- Complete effort selector including `max`, with capability warnings.
- Codex multi-agent configuration UI (real spawning is not device-tested).
- Removed Send Error Report button entry points.
- Android versionCode 76 for in-place upgrades from compatible signed builds.

### Important

The APK is unverified on a physical device. Compatible installation requires the same Android package ID and signing certificate. Do not uninstall the old app to update; uninstalling normally clears local configuration. Verify file SHA-256 against `SHA256SUMS`.
