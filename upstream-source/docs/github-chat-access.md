# GitHub 登录与聊天工具

GitHub 登录保存在 Android 原生层，通过本机凭据服务连接到内置 Git。模型使用现有 shell 工具即可执行 Git HTTPS 的 clone、fetch、push；不依赖额外的 GitHub MCP 服务或 `gh`。上传源码仍使用 Git 提交及推送，遵守用户授权范围。

0.3.9-cn.8 修正了仍要求用户另行提供 Git 凭据的旧指令。每次开始新一轮任务时，聊天会接收当前 GitHub 状态、账号和权限；登录、退出或过期会让同一远端会话更新指令，不需要清空聊天。运行中的一轮可使用以下命令读取即时状态：

```sh
python3 "$MC_GITHUB_CLI" status
python3 "$MC_GITHUB_CLI" repos --page 1 --per-page 30
```

`status` 仅读取本机状态。`repos` 使用当前登录调用固定的 GitHub HTTPS 接口，列出该账号拥有的公开仓库，返回仓库名、HTTPS 地址、推送权限、归档状态和下一页编号。仓库列表命令不提供任意 URL 或写入接口；私有仓库不在当前 `public_repo workflow` 授权范围。

凭据不加入模型指令或普通命令输出。仓库列表请求不跟随重定向，响应有大小限制，错误不回显原始响应、请求头或异常。Git 的凭据 helper 协议本身包含令牌，因此诊断时禁止输出 helper 结果、执行会打印令牌的 `git credential fill`，或转储凭据服务环境变量。

回归覆盖原生登录状态筛选、同一聊天登录/退出后的指令刷新、凭据服务状态查询、真实 Python 子进程与本机服务联通，以及仓库列表分页、断开状态、HTTP 错误、重定向和响应上限。自动化使用测试凭据和网络响应，不表示已用用户安装版的私有凭据完成真实推送验收。
