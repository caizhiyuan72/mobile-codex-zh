# 图片附件预览

`0.3.9-cn.7` 修复 API 版选择图片后输入区被图片固有尺寸撑满的问题。此前附件渲染仍生成 `.draft-context`、`.context-chip` 和 `.context-image`，但界面整理时遗漏了相应尺寸样式。

附件区现在使用一排可横向滚动的标签，限制整体高度；图片预览固定为 44 × 44 CSS 像素，长文件名省略显示。点击缩略图仍可打开图片查看器，删除按钮仍保留 44 像素触控区域。缩略图仅改变显示尺寸，不改变附件原文件或发送内容。

`node tools/verify_api_ui_browser.cjs` 在真实 Chromium 中检查：

- 320、360、412、768 像素宽度及明暗主题。
- 超长截图、超宽图片、大方图、多附件和长文件名。
- 420 像素短视口下聊天区、输入框和发送按钮仍然可见。
- 图片放大、单个附件删除、文字草稿保留和页面重载后的附件恢复。
- 发送后的图片仍使用消息缩略图，删除全部附件后隐藏空附件区。

布局测试使用本地合成图片和模拟原生桥接，不连接模型服务，也不代表已经在 Android 真机中操作验收。

该修复沿用 Codex CN API 的包名和签名，通过增加版本号更新当前 API 版。
