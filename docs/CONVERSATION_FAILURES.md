# 长对话请求失败

cn.9 的待发布修订为失败对话保留固定说明。提示随原对话保存，切换到其他对话不会显示；重新发送被接受或后续请求完成后清除。正在重试的流式错误不会提前显示最终失败。提示和诊断分类不保存服务商原始 HTTP 正文。

如果服务商以 HTTP 409 返回 `The proven encrypted agent transport changed.`，界面明确说明加密会话传输冲突。已检查的失败记录中，长对话自动压缩也遇到了该响应；另有独立的 503、525 和流解码失败，所以不能把所有重连归为同一原因。这是实际返回错误的分类，不是已修复服务商会话恢复的承诺。

失败提示提供“复制说明”和“打开新对话”。新对话保留当前项目选择，用户需补充任务进度；原对话和项目文件保留。此入口不会自动迁移历史、伪造摘要、替换旧线程 ID 或更换模型。可向服务商提供固定错误说明，请其检查原端点和会话路由。

验证覆盖错误分类、重试与最终失败、错误持久化、后台会话隔离、成功后清除、新对话项目选择和重发草稿保留。服务商恢复及 Android 真机交互仍需实际验收。
