# 大肥龙独立安装版

应用名为“大肥龙”，包名 `dev.mobilecodex.app.zhcnv3.fresh`，源码版本 `0.3.9-cn.26` / `97`。它使用独立签名，可与 V5 和 Codex CN API 同时安装，无需旧版私钥。`upstream-source/icon-pack/dafeilong/` 中的 `white-original.png` 用于桌面图标，`in-app-original.png` 用于首页、侧栏和悬浮窗头像。运行 `node upstream-source/tools/prepare_fresh_icon.mjs` 可重新生成这两套资源。通知小图标使用单色龙角轮廓。

任务结果使用独立的高优先级通知渠道。点击通知会打开对应对话，手动回到该对话也会清除其结果通知。是否显示顶部横幅或播放提示音由系统通知设置控制。只有单个任务明确等待人工审批、且没有并行子任务、终端命令或 Linux 安装时，才暂停任务唤醒锁及定时检查；回应审批时恢复。工作记录和代码差异的密集更新合并保存，回合结束仍立即保存。

模型 API 设置默认显示三个服务商，优先显示当前启用的服务商。其余服务商、模型 ID 和添加表单通过对应入口展开。在设置中添加多个 API 后，新聊天可从顶部 API 标签选择服务商。发送首条消息后，聊天记住所选服务商。返回历史聊天时，顶部显示该聊天的服务商。不同服务商的任务可以同时运行。

助手回复支持 LaTeX。行内公式使用 `\(...\)` 或 `$...$`，独立公式使用 `\[...\]` 或 `$$...$$`。公式和字体由应用本地渲染，过宽的独立公式可以横向滑动。

设置顶部的「界面主题」可在「原版」和「液态玻璃」之间切换，默认使用原版。液态玻璃为导航和输入栏提供背景模糊、透光和边缘高光，并支持浅色和深色模式。应用会记住所选主题，切换时保留对话、阅读位置和草稿。

侧栏项目「＋」默认打开大肥龙的主文件夹，可关联现有子文件夹、新建项目文件夹，或通过 Android 选择其他位置。对话运行时也能添加项目，当前对话和任务继续保留；导入、合并和重新绑定不受这项改动影响。

项目绑定到可写文件夹后，应用会在项目根目录准备「大肥龙输出」，旧项目打开根目录时也会补建。应用会保留已有的同名文件、目录和原「输出」里的内容。只有聊天记录的项目在绑定文件夹后才有实际的输出目录。

聊天里的 Markdown 文本块和代码块可以单独复制。切换同一项目内的对话只更新侧栏选中项，不重建对话列表；设置不再提供图包入口。文件侧栏可编辑工作区内的 UTF-8 文本并预览支持的图片；不再提供独立的 Root 文件访问组件。

有更早的聊天记录时，可点聊天顶部的「加载更早的消息」。如果当前内容不足一屏，点按后从新加载的内容开始看。已能滚动的聊天也支持滑到顶部继续加载，并保持阅读位置。

命令、文件修改和网页搜索按出现顺序保存在聊天中。同一段连续工具记录里的已完成操作合为一条摘要，展开后可查看各项详情。正在执行的操作单独显示。最终回复出现后，用户消息之间的连续工作过程合为一组，点击「查看工作过程」可单独展开该组。旧记录在打开历史聊天时尝试从本地引擎的聊天记录恢复。上翻会暂停自动跟随，只有当前对话收到新回复内容才出现「最新消息」；点击按钮或滑回底部恢复跟随。输入框左上方每秒更新一次计时，收到新的命令等任务进展后归零。模型入口使用紧凑的胶囊按钮，菜单中分开显示当前模型和推理档位。拖动滑块时，滑轨和滑块圆点会随档位变色，并保存所选档位。使用 `ultra` 时，本版内置引擎在模拟 Responses 请求中使用 `max` 强度。

构建目标为 `testFreshUnitTest lintFresh assembleFresh`。CI 核对实际 APK 名称、包名、版本、ARM64、minSdk 29、非调试配置、ZIP 对齐及全部 Web 资源，提供 unsigned 构建附件和经过实际重建验证的下载套件。附件名为 `dafeilong-fresh-build-<commit>` 和 `dafeilong-fresh-download-kit-<commit>`。unsigned 文件不能安装。

永久签名材料保存在仓库 Actions Secret `DAFEILONG_SIGNING_JSON`，结构与 API 版签名工具一致，但采用独立的 RSA 3072 位新密钥。公开证书固定在 `fresh-release-policy.json`，SHA-256 为 `ecfc26efdc5cb36beb7a8773f73c105c8fe72fc03e634399f46f7d462d567b94`。受信任的 push 或手动构建自动签名，输出可安装附件 `dafeilong-signed-<commit>`；PR 不读取密钥，不签名。构建只读取已有 Secret，不会每次生成新密钥。

后续制作“大肥龙”更新直接运行同一工作流，无需再寻找旧 V5 私钥。递增应用版本后，使用相同包名和已保存的新密钥升级。不要删除或覆盖该 Secret。GitHub Secret 不能下载原值，额外的加密恢复备份保存在生成密钥的应用私有存储，密码与备份分开保存；不要清除唯一备份。

首次启动需要重新设置服务商和 API 密钥、授权项目文件夹。应用数据按包名隔离，旧对话仍在旧版中。后续“大肥龙”更新应沿用其新签名密钥；旧 API 版的固定证书只适用于 `.next`，不适用于此独立应用。
