# Changelog

## v0.3.9-cn.5 (prepared, not yet published)

- Shortened launcher display name to Codex CN.
- Added visible effort options: automatic, none, minimal, low, medium, high, xhigh, max.
- Included model/provider capability indications and experimental requests for unsupported levels.
- Added settings entry for native Codex subagents and concurrency controls.
- Removed the visible Send Error Report entry points.
- Preserved package ID and signing certificate relative to the prior Codex CN v4 build; incremented Android versionCode from 75 to 76.

### Limitations

- No physical-device installation or actual remote API/agent-spawn test has been demonstrated here.
- API providers may reject unrecognized reasoning effort values.
- Publishing the APK on a public repository requires GPL-3.0 corresponding-source compliance.
